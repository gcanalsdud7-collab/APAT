웹 주소로 응시한 기록이 있어요

이 브라우저에 웹 주소로 이용할 때의 응시 기록 0건이 남아 있어요. 파일로 내보낸 뒤, 다운로드한 APAT의 응시 기록 → 기록 가져오기로 옮겨 주세요.

사용 방법

  1. 다운로드위 버튼으로 APAT.html을 받아요.
  2. 더블클릭해서 열기Edge 또는 Chrome에서 열려요. 인터넷 연결 없이도 실행돼요.
  3. 시험 선택 후 응시문제·해설 PDF를 선택하면 바로 시작해요.

응시 기록 보관

  • 응시 기록은 이 컴퓨터의 브라우저에 저장되며, 어디에도 전송되지 않아요.
  • 새 버전을 다운로드해도 같은 브라우저로 열면 기록이 그대로 이어져요. 파일 위치나 이름이 달라도 돼요.
  • 브라우저의 인터넷 사용 기록(쿠키·사이트 데이터)을 삭제하면 기록도 지워지니, 가끔 응시 기록 → 기록 내보내기로 백업해 주세요.
  • 다른 컴퓨터나 브라우저로 옮길 때도 내보내기·가져오기를 이용해요.
