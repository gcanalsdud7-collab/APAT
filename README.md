# APAT — All-in-one Pre-Aptitude Test

인적성 검사(GSAT, SKCT, LG, HMAT, PAT, CJ, L-TAB 등) 실전 연습 프로그램이에요.
문제 PDF를 불러와 실제 시험처럼 시간을 재며 풀고, 해설 PDF의 정답표로 자동 채점해요.

## 다운로드

- **[APAT 다운로드](../../releases/latest/download/APAT.html)** — APAT.html 파일을 받아 더블클릭하면 Edge·Chrome에서 실행돼요. 인터넷 연결 없이도 동작해요.
- 업데이트 내역과 사용 방법은 저장소 오른쪽 About의 안내 페이지 링크에서 볼 수 있어요.

- 문제·해설 PDF는 이용자의 컴퓨터 안에서만 처리되며 어떤 서버에도 업로드되지 않아요.
- 응시 기록은 이 컴퓨터의 브라우저에만 저장돼요. 새 버전을 다운로드해도 같은 브라우저로 열면 기록이 이어져요. 백업이나 다른 기기로 옮길 때는 응시 기록 화면의 '기록 내보내기·가져오기'를 이용해 주세요.

## 주요 기능

- **실전 프리셋**: 시험별 실제 구성(문항 수·제한 시간·시간 종료 처리·제공 도구)으로 응시, 끄면 응시할 영역만 골라 직접 설정
- **영역 자동 나누기**: 시험 시작 페이지만 지정하면 문항 번호를 읽어 영역별 페이지 범위를 자동 지정
- 스캔본·텍스트 PDF의 선지(①~⑤) 자동 인식 — 2단 배치, 지문 속 선지, 그래프형 선지, 두 페이지에 걸친 선지 포함
- 문제 위에서 바로 클릭해 응답, 해설 PDF의 정답표로 자동 채점(채점 전 정답 검증)
- SKCT 이전 문항 제한, 메모장·그림판·계산기(시험별 제공 도구), 실물 교재용 화면 답안지
- 영역별 정답률·풀이 시간 추이와 취약 영역 진단, 실전/연습 기록 구분, 오답 노트와 다시 풀기

## 교재 저작권 안내

타인의 저작물(출판 도서, 문제집 등)을 권리자의 허락 없이 무단 복제·가공하여 프로그램에 입력하거나 타인에게 배포·공유하는 행위는 저작권법 위반에 해당할 수 있으며, 이로 인해 발생하는 일체의 민·형사상 법적 책임은 이용자 본인에게 있습니다.

이 저장소에는 프로그램만 포함되어 있으며, 어떠한 교재 내용도 포함되어 있지 않아요.
