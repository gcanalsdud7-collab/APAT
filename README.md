# APAT — All-in-one Pre-Aptitude Test

인적성 검사(GSAT, SKCT, LG, HMAT, PAT, CJ, L-TAB 등) 실전 연습 프로그램입니다.
문제 PDF를 불러와 실제 시험처럼 시간을 재며 풀고, 해설 PDF의 정답표로 자동 채점합니다.

## 바로 사용하기

- **[APAT 실행하기](https://gcanalsdud7-collab.github.io/APAT/)** — 설치 없이 브라우저(Edge, Chrome 권장)에서 열립니다.
- **[APAT 내려받기](https://github.com/gcanalsdud7-collab/APAT/releases/latest/download/APAT.html)** — 파일을 받아 더블클릭하여 실행합니다.

- 문제·해설 PDF는 이용자의 컴퓨터 안에서만 처리되며 어떤 서버에도 업로드되지 않습니다.
- 응시 기록은 사용 중인 브라우저에만 저장됩니다. 다른 기기로 옮기려면 응시 기록 화면의 '기록 내보내기'를 이용하십시오.
- 내려받은 파일도 실행할 때 인터넷 연결이 필요합니다(PDF 처리 부품을 불러오기 위함).

## 주요 기능

- 스캔본·텍스트 PDF의 선택지(①~⑤) 자동 인식, 문제 위에서 바로 클릭하여 응답
- 해설 PDF의 정답표 자동 인식 및 채점, 채점 전 정답 검증 단계
- 영역별 제한 시간, 문항별 소요 시간, 결과 분석과 응시 기록 추이
- 메모·그리기·계산기 도구(GSAT 모드는 도구 없음)
- 실물 교재 모드(화면 OMR 답안지), 오답 노트, 중단한 시험 이어서 응시

## 교재 저작권 안내

타인의 저작물(출판 도서, 문제집 등)을 권리자의 허락 없이 무단 복제·가공하여 프로그램에 입력하거나 타인에게 배포·공유하는 행위는 저작권법 위반에 해당할 수 있으며, 이로 인해 발생하는 일체의 민·형사상 법적 책임은 이용자 본인에게 있습니다.

이 저장소에는 프로그램만 포함되어 있으며, 어떠한 교재 내용도 포함되어 있지 않습니다.
